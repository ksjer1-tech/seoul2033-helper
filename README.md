# 서울 2033 도우미 (안드로이드)

게임 화면을 보고 Claude가 추천 선택지와 필요 능력치를 화면 위 말풍선으로 알려주는 앱입니다.

## APK 만들기 (PC 없이 GitHub로)
1. github.com 에서 새 저장소(Private 추천)를 만듭니다.
2. 이 폴더의 파일을 모두 올립니다 (`.github` 폴더 포함).
3. 저장소의 **Actions** 탭 → `Build APK` 실행이 끝날 때까지 3~5분 기다립니다.
4. 완료된 실행을 열고 **Artifacts**의 `seoul2033-helper-apk`를 받아 압축을 풀면 `app-debug.apk`가 있습니다.

Android Studio가 있으면 폴더를 열고 Run 해도 됩니다.

## 설치와 사용
1. APK 설치 (출처를 알 수 없는 앱 허용 필요)
2. 무료: aistudio.google.com 에서 Gemini API 키 발급 후 앱에 입력 (기본 선택이 Gemini)
   유료: console.anthropic.com 에서 Claude API 키 발급 후 입력하고 Claude 선택
   Gemini 모델 이름 기본값은 gemini-2.5-flash. 404 오류가 나면 AI Studio에서 보이는 무료 모델 이름으로 바꾸세요.
   무료 한도가 작아서 자동 모드보다 🎯 탭으로 필요할 때만 쓰는 걸 추천합니다.
3. [시작] → '다른 앱 위에 표시' 허용 → 화면 녹화에서 '앱 하나' → 서울 2033 선택
4. 🎯 탭: 지금 화면 분석 / 길게: 자동 모드 / 드래그: 이동
5. 말풍선 탭: 접기·펴기

## 참고
- 비용: 분석 1회에 Sonnet 약 1~2센트, Haiku는 그보다 저렴 (요금은 바뀔 수 있음)
- 자동 모드는 화면이 바뀌고 멈췄을 때만 보내서 비용을 줄입니다.
- 숨겨진 확률이나 결과는 AI도 정확히 모를 수 있습니다.
- 끄기: 알림의 [중지] 또는 앱의 [중지]
